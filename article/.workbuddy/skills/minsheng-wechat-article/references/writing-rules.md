# 写作规则：去 AI 味、用词准确、语句通顺

这份文档是成稿质量的主要抓手。写作与改稿时反复对照，尤其是 A、B 两张表。

## A. AI 味高频词表

### 直接禁用

赋能、抓手、闭环、链路、颗粒度、对齐（业务语境）、拉通、打法、生态位、心智、护城河、势能、深度赋能、全面赋能、注入新动能、开启新篇章、按下加速键、跑出加速度、交出答卷

### 慎用（出现即检查，通常可以直接删）

| 词/句式 | 问题 | 改法 |
| --- | --- | --- |
| 值得注意的是 / 值得一提的是 | 纯提示语，无信息 | 删掉，直接说 |
| 总而言之 / 综上所述 | 结尾凑字 | 删掉或换成一句结论 |
| 近年来 / 随着……的不断发展 | 万能开头 | 换成具体时间或具体变化 |
| 在当今……的时代 | 空铺垫 | 删 |
| 不仅……更是…… | 模板对仗 | 拆成两句直说 |
| 这意味着 / 换言之 / 换句话说 | 滥用 | 保留一次可以，多次删 |
| 极大地 / 充分地 / 有效地 / 进一步 / 切实 | 空转副词 | 删，或换成具体程度 |
| 引发了广泛关注 / 成为热议话题 | 无信息 | 换成具体的讨论焦点 |
| 从某种程度上说 / 在某种意义上 | 模糊限定 | 删，直接给判断或给出条件 |
| 让我们 / 让我们一起 | 煽动式号召 | 删 |
| 相信在不久的将来 | 空头预期 | 删 |
| 为……提供了有力支撑 | 八股 | 改写为具体作用 |
| 成为一个值得深思的问题 | 空泛 | 换成具体疑问 |

## B. 句式禁忌

- **三连排比**：「更便捷、更高效、更贴心」——删到只剩一个最关键的
- **段落等长**：每段行数几乎一样，一眼就是机器写的——故意做出长短差异
- **节节总分总**：每一节都是「观点 + 展开 + 小结」——去掉大部分小结
- **小标题对仗**：「政策之变 / 民生之暖 / 未来之盼」——换成说人话的小标题
- **万能开头段**：先讲背景、再讲意义、最后才进入主题——第一句就进入主题
- **口号式结尾**：「让我们一起期待更美好的明天」——换成一句具体的、落在读者身上的话
- **长定语套娃**：「对于在本地参保满十年的灵活就业人员来说」——拆成主谓
- **被动句泛滥**：「政策被修订」「问题被解决」——换成主动
- **名词化表达**：「对落实情况进行了检查」——「检查了落实」
- **破折号、分号滥用**——大多可以改成句号
- **口语化短句收尾**：「……比什么都准」「别拖到最后几天」——见 G 节，这是暴露 AI 最狠的一类

## C. 民生文章推荐结构

```
开头
  ├ 一个具体场景，或读者最常问的那个问题
  └ 直接给出核心结论：这件事对你意味着什么

主体（2-3 节）
  ├ 每节只解决一个问题
  ├ 采用「规定是什么 → 对读者意味着什么」的双层写法
  └ 小标题用说人话的短句

怎么办（1 节）
  └ 可执行动作：找谁、带什么、去哪、什么时候截止

注意事项（可选，1 节）
  └ 例外、边界、常见误解

结尾
  └ 一句话收束，落在读者身上，不喊口号
```

**双层写法示例**

> 规定层面：灵活就业人员在就业地参加职工基本养老保险，缴费比例由 20% 调整为 19%。
> 读者层面：如果你自己在交社保，每月最低档大约少缴 87 元，一年少 1000 多块；待遇算法不变。

### C1. 信息编排：把读者最想查的放前面

**判断标准**：读者打开这篇文章，第一个动作是想找什么？

| 读者状态 | 第一个动作 | 该内容应放在 |
| --- | --- | --- |
| 行程已定 | 查我要去的那里 | 快查表，第 2 屏内 |
| 还在选 | 看哪个方向整体好 | 全国概况 + 区域对比 |
| 关心风险 | 查哪里会出问题 | 风险提示节 |

**三条硬规则**

1. **快查表前置**。城市表、景区表、价格表、平台表一律放在「整体概况」之后、「详细分述」之前。信息型文章的价值在快查，读者不该翻到倒数第二节才拿到答案。
2. **小标题用读者自己的词**。用省份名、城市名、事物名，**不用行业术语与分区名**。
   - 反例：江淮、黄淮、江汉、江南、西南地区东部、东北地区南部——读者无法判断自己属哪个区，且这些词在搜一搜里是零命中。
   - 正例：江苏、安徽、湖北、湖南、四川东部。
   - 例外：专业统计口径不能改的（如气温距平按「江南、华南」发布），改动会失真，保留原表述。
3. **同一信息不重复**。表格里已有的逐条数据，正文不再单列一遍；正文只写表格覆盖不到的增量（时序变化、区域差异、成因、后果）。

> 这条规则可推广到所有题材：凡是用行业术语做小标题的，都换成读者自己的词。「灵活就业人员社保」要留（这是读者的原话），「江汉地区」「黄淮一带」要换掉。

### C2. 题材落点：把资讯翻译成服务

民生号与资讯号的分界，不在选题，而在**文章有没有回答"所以呢"**。同一个选题，两种写法：

| 题材 | 资讯写法 | 民生写法 |
| --- | --- | --- |
| 天气 | 降水落区、气温距平、冷空气过程 | 什么时候出门合适、高速免费到几号、哪段路雨天危险 |
| 政策 | 文件名称、条款编号、实施范围 | 谁能办、怎么办、要什么材料、什么时候截止、逾期怎样 |
| 数据 | 同比环比、统计口径 | 和你所在地区、你这类人有什么关系 |

**判据**：删掉这篇文章，读者损失的是「知道了」还是「用得上」？只有「知道了」，就是资讯稿。

**常见题材的落点清单**

- **天气**：出行时间（高峰时段、免费政策）、生活安排（洗晒、户外、着装）、安全（积水、结冰、火险）、体感（温差与降温幅度）
- **政策**：谁能办 → 办什么 → 要什么材料 → 什么时候截止 → 逾期后果
- **补贴/消费**：参与门槛、在哪领、怎么领、什么时候到账、常见不予受理情形
- **价格/收费**：涨了多少、什么时候执行、对哪类人多花多少钱

**写法**：落点用**事实与后果**陈述，不用叮嘱口吻。写「10 月 7 日是免费通行最后一天，临近 24 时截止时点，部分路段可能出现短时集中驶出」，不写「建议提前下高速」。

**一个反直觉的提醒**：给天气稿加民生落点时，最容易补的是交通——因为"出行高峰 × 天气"的交叉才是读者真正要做的决策。交通部门的出行提示里有现成的官方预测（高速免费时段、流量峰值日、返程高峰时段），比气象数据更贴近读者的动作，值得单独成节。

### C3. 标题：题材词之外，必须有落点词

标题与正文适用同一条判据。**题材词**（"天气""政策""通知"）只说明文章写的是什么，**落点词**（"高速免费 7 天""最高 1 万元""这几个省已启动"）才说明读者能得到什么。

| 只有题材词 | 补上落点词 |
| --- | --- |
| 国庆假期天气出炉，南方先雨后晴，北方秋高气爽 | 国庆假期天气预报，南方先雨后晴，高速免费 7 天 |
| 有奖发票第二波启动：湖北、河南、重庆均已开展 | 有奖发票第二波，最高 1 万元，重庆每月抽 100 个 |

三条要求：

1. **至少一个落点词，且压在列表页展示的前 20 字内**——20 字之后的读者看不到。
2. **核心检索词完整前置**。"国庆假期天气预报""有奖发票"是真实存在的高频搜索词，不要拆开，也不要换同义说法。
3. **无冒号、无感叹号、无催促**（"千万别错过""建议收藏""最后一波"）。

**尺度**：标题可以比正文松一档，但不能松到正文接不住。正文守民生平实语体，标题适度争取点击；反过来把标题也写成公文腔，点击会明显受损。

## D. 删改三遍法

### 第一遍 · 删

- 删过渡句：「说完了 A，我们再来看 B」「接下来」「那么」
- 删提示句：「需要注意的是」「这里要特别说明」「不难发现」「我们可以看到」
- 删段落末尾重复本段意思的那一句
- 删没有信息量的形容词副词：「非常重要的」「十分」「相当」
- 删空转主语：「我们可以看到，目前……」

**目标：信息不减少。** 字数不设削减指标——删的标准是「这句删掉，读者少知道什么」，不是「删够多少字」。

### 第二遍 · 换

- 抽象 → 具体：「很多人」「大部分家庭」→ 给出比例、数据，或一个真实的场景
- 被动 → 主动
- 名词化 → 动词
- 长定语 → 短句
- 书面连接词 → 口语连接词：「因此 / 然而」→「所以 / 但是」（民生文可适度口语化）
- 生僻词 → 常用词：「施行」可以，「付诸实施」不必

### 第三遍 · 读

出声读一遍，凡舌头打结处就是不通顺处：

- 单句超过 40 字 → 断开
- 单段超过 4 行（手机屏）→ 断开
- 一句里三个以上逗号 → 改写成短句
- 连续三句同结构 → 改掉一句

## E. 读者视角转换表

民生文章最大的问题不是写得难看，而是**站在文件那一侧说话**。

| 文件语言 | 读者语言 |
| --- | --- |
| 进一步优化调整住房公积金提取政策 | 公积金提取放宽了，这几种情况不用再跑窗口 |
| 按规定享受相应待遇 | 符合这几个条件，就能领到这笔钱 |
| 建立待遇动态调整机制 | 这笔钱以后会跟着变，不是一次定死 |
| 加强灵活就业人员权益保障 | 自己交社保的人，这次多了两项保障 |
| 符合条件的可于规定期限内申请 | 10 月 31 日前提交申请，过期要重新排队 |
| 统筹推进相关配套改革 | 具体怎么改，下面三条最关键 |

转换口诀：**先问「读者会怎么问」，再答「官方怎么定」。**

## F. 用词准确性细则

- 数字用阿拉伯数字，但成句的概数可用汉字：「三四个」「十几种」
- 金额统一格式：`1,200 元` 或 `1200 元`，全文一致
- 时间写全年份：「3 月 15 日」→ 首次出现时写「2026 年 3 月 15 日」
- 政策名称首次出现用全称，之后可用简称，并在括注中说明
- 机构名称用规范全称，不用网络简称
- 「医保」与「社保医保」区分清楚，「养老保险」与「养老金」区分清楚
- 不造词、不用网络生造缩写（除非是读者普遍使用的，如「医保」「公积金」，且首次出现给出全称）

## G. 口吻自检：什么在暴露 AI

词表干净、句式规范，文章仍可能一眼被认出是机器写的，问题就出在口吻。机器习惯替读者下判断、给情绪、催动作，而民生稿只陈述事实和后果。

### G1. 独立成句的短促判断（最高频）

把一句口语化、带情绪的短句单独成句甚至单独成段，用来收尾、强调或催促。它不含信息，只有姿态。

| 暴露 AI 的写法 | 问题 | 改法 |
| --- | --- | --- |
| ……比什么都准。 | 替读者下结论，口语 | 具体规则以当地主管部门公告为准。 |
| 别拖到最后几天。 | 催促式，营销号腔 | 活动资金使用完毕即提前结束。 |
| 这一点很重要。／记住这句话。 | 空提示 | 删掉，或直接写出后果 |
| 真的。／确实如此。 | 情绪补丁 | 删 |
| 说白了／讲真／有一说一 | 网络口语 | 改为书面陈述 |
| 划重点／敲黑板／重点来了 | 口播腔 | 删，直接写内容 |
| 千万别／一定要／赶紧／记得 | 祈使式催促 | 改成条件句或陈述句 |

判断标准：**删掉这句，读者得到的信息有没有减少。** 没有减少，它就是在装语气。

### G2. 加粗短句充当段落开头

`**谁出钱变了。** 第一波是……` 这种「加粗短标签 + 正文」的写法，短、口语、句子不完整，是机器排版习惯。

- 该分节的，改用规范小标题（`###`）
- 不该分节的，写成完整的第一句，加粗只留给关键词

```
✗ **谁出钱变了。** 第一波是中央财政掏钱。
✓ ### 出资主体由中央变为地方
  第一轮由中央财政安排 100 亿元……

✗ **中奖后别急着红冲。** 如果退货……
✓ 中奖后退货的，发票作废，已发放奖金需全额退回。
```

### G3. 口语化拟人与生动化

- 「那一轮到点收尾了」→「该轮试点于 7 月 31 日到期」
- 「第二波来了」→「新一批活动于 9 月启动」
- 「买点东西、吃顿饭、住个店」「多问一句」→ 改为规范表述
- 拟声、拟人、网络热词、颜文字，标题与摘要内一律不用

### G4. 该守的语体

**基调：平实、正常对话、有读者在场。** 像一位把文件读懂了的人，用日常语言把事讲给读者听。既不是机关通稿，也不是自媒体。

三条落地做法：

1. **读者在场**。把「你这类人」的位置写进段落，而不是通篇无主语地陈述。
   - ✗ 现就有关事项说明如下。／2025 年，全国依法办理结婚登记 676.5 万对。
   - ✓ 准备结婚或者刚登记的人，下面两块可以直接对照。／2025 年，全国结婚登记 676.5 万对。
2. **文件语言翻译成人话**。文件原文只在关键处引一句，其余译成日常说法。引号和条款号留给出处，正文不再复述一遍。
3. **允许设问与导航句**。读者真正会问的那个问题可以直接问出来（「婚假能休几天？」），段落之间可以用「下面先说数据，再说婚假怎么休」过渡。这是正常对话，不是噱头。

**仍然不允许**：撒娇、催促、抖机灵、替读者抒情，以及 G1—G3 的三类（口语化短句收尾、加粗短句打头、口语化拟人）。

**判据**：把这句话念给一位没看过文件的人听。他听不懂，就改；听懂了但觉得像在被训话，也改。

### G5. 民生细分类别与对应语气

民生号不是一种语气。先判断这篇属于哪一类，再决定怎么说话。

| 细分 | 读者的状态 | 该用的语气 | 该先给什么 |
| --- | --- | --- | --- |
| 政策解读 | 听说有变化，想知道跟自己有没有关系 | 先讲变化，再落到「你这类人怎么办」 | 变化本身 → 适用对象 → 怎么算 |
| 办事指南 | 已经决定要办 | 直给条件和步骤，不铺背景 | 去哪办、带什么、多久出结果、截止日 |
| 生活服务（天气、出行） | 明天就要出门 | 给场景判断，不报趋势 | 几点雨最大、哪条路危险、穿什么 |
| 数据发布 | 看到新闻，想辨真假 | 先给来源和数字，再给读者的位置 | 数字 → 口径 → 与你所在地区的关系 |
| 权益维护 | 已经遇到问题 | 谁能办、找谁、什么时限 | 责任主体 → 依据 → 救济途径 |

**混合题材按读者的第一疑问定语气。**「结婚登记数据 + 婚假规定」这种组合，读者的第一疑问是「我能休几天」，语气就按政策解读走；数据在前还是在后都可以，但语气不能被数据带走，否则会写成统计公报的口播。


## H. 成稿自查问题

1. 有没有哪句话，删掉之后读者得到的信息变少了？
2. 第一段是不是在讲背景？如果是，删掉重写。
3. 每个小标题，是不是都能让读者知道这节在说什么？
4. 有没有一句话是写给「我自己交差」而不是写给「读者看」的？
5. 大声读一遍，哪里卡壳？
6. 通读一遍，**有没有哪一句读起来像在跟读者说悄悄话、或者在催他赶紧行动？** 有，改成陈述句。
7. 通读一遍，**有没有哪一句像在念文件**（「依法办理」「同步公布」「文件明确」「现将有关事项通知如下」）？有，换成读者日常说法。改完再念一遍：像被训话吗？
