# 信源标准与事实核验

民生文章出错，九成错在信源。这份文档规定「什么能用、去哪找、怎么核」。

## 一、信源分级

### S 级 · 一手官方（直接引用，无需回溯）

- 国家法律法规数据库 `flk.npc.gov.cn`
- 中国政府网 `gov.cn` 及「政策」栏目
- 国务院组成部门官网：人力资源社会保障部 `mohrss.gov.cn`、国家医保局 `nhsa.gov.cn`、教育部 `moe.gov.cn`、住房和城乡建设部 `mohurd.gov.cn`、国家统计局 `stats.gov.cn`、国家发展改革委 `ndrc.gov.cn`、国家市场监督管理总局 `samr.gov.cn`、国家卫生健康委 `nhc.gov.cn`、民政部 `mca.gov.cn`、财政部 `mof.gov.cn`
- 省、市、县政府门户网站与对应部门官网
- 国务院政策例行吹风会、部委新闻发布会的官方实录
- 政府公报、法规汇编
- 新华社、人民日报、中央广播电视总台的**署名**报道与通稿

### A 级 · 权威二手（可用，但关键结论要回溯到 S 级）

人民网、新华网、央广网、中国新闻网、光明日报、经济日报、法治日报、地方党媒，以及上述机构的客户端与官方账号。

### B 级 · 参考（需两个以上独立来源交叉验证）

主流都市报、财经媒体（财新、第一财经、21 世纪经济报道、经济观察报）、行业垂直媒体。

### C 级 · 仅作线索（不得作为唯一依据）

自媒体、内容聚合号、短视频转述、问答社区回答、AI 生成的摘要、无署名的「网传」「据悉」。

**发现 C 级线索后，必须回到 S 级或 A 级找到原始出处**；找不到就放弃这条事实。

### 禁用

- 无法定位原文的截图
- 营销号发布的「统计数据」
- 来源不明的「有关部门表示」
- 把旧闻当新闻
- 把个人解读当官方口径

## 二、去哪查（按题材）

| 需求 | 渠道 |
| --- | --- |
| 政策条文、法规原文 | 国家法律法规数据库、政府网政策库、部门官网「政策文件」栏 |
| 政策解读、答记者问 | 政府网「政策解读」、部门官网「解读」栏、新闻发布会实录 |
| 统计数据 | 国家统计局、部门统计公报、地方统计年鉴 |
| 房价与物价 | 统计局 70 个大中城市住宅销售价格、CPI / PPI 月度数据 |
| 社保医保咨询 | 12333（人社）、12393（医保）、12345（政务综合） |
| 办事流程 | 各地政务服务网、政务 App 的办事指南 |
| 教育升学 | 教育部阳光高考平台、各省教育考试院 |

## 三、事实核验清单

每一条进入正文的事实，逐项过一遍：

1. **文件全称**是什么？发文字号是什么？
2. **发布机关**是哪个？发布日期？施行日期？
3. 是否**现行有效**？有没有被新文件替代、废止或修订？
4. **适用范围**是什么？有没有例外条款、排除情形？
5. **数字**是否来自原始发布口径？单位是否一致（元 / 万元、月 / 年、人 / 人次）？
6. 我引用的是**原文**还是媒体转述？转述有没有偏差？
7. **时效**：是否仍在有效期内？过渡期、截止日是什么时候？
8. **地域**：全国口径还是某省市口径？地方差异是否已说明？

任何一项答不上来，这条事实就不能写进正文。

## 四、时效管理

- 政策类文章必须在文中标注有效时间锚点，如「截至 2026 年 9 月」或「自 2026 年 7 月 1 日起」
- 发布超过 1 年的政策，引用前必须重新确认是否仍现行有效
- 谨慎使用「最新」「刚刚」「近日」——除非该时间点可被验证
- 涉及调整、过渡、分批实施的，要写清不同时间节点的差异

## 五、表述纪律

区别对待这些词，不要混用：

- **规定 / 建议 / 研究 / 试点** —— 强制性完全不同
- **可以 / 应当 / 必须** —— 自愿、倡导、强制的界线
- **全部 / 部分 / 符合条件的人员** —— 覆盖范围不能扩大

原文模糊的地方，保持模糊，不要替它确定化。
原文没有下结论的地方，不要替它下结论。
原文说的是「逐步推进」，就不要写成「马上落地」。

## 六、数据呈现

- 钱换算成读者能感知的尺度：不说「提高 8%」，说「每月多领 120 元，一年 1440 元」
- 比例要给基数：「参保率 95%」不如「1.2 亿人参保，覆盖率 95%」
- 大数用读者熟悉的参照：「相当于每人每年多出半个月工资」
- 涉及跨年对比的，标明对比口径是否一致

## 七、引用与标注

- 正文中自然带出出处，如「人社部在今年 3 月的通知里明确」，不生硬加脚注编号
- 关键政策可附文件全称，方便读者自己核验
- 大段原文不照抄，以转述为主；必要引用加引号
- 文末附来源清单：事项 —— 文件/链接 —— 发布单位 —— 发布日期
- 引用他人报道或观点需标注来源，涉及图片需确认版权与肖像授权

## 八、天气与预报类事实

天气稿最容易犯的错，是把「预报」写成「实况」，或把别的城市、别的时段的数据挪过来用。

- **信源优先级**：中国气象局 / 中央气象台 > 国家气象中心专报 > 省市级气象台发布会与专报 > 中国天气网 > 媒体转载。媒体报道只作线索，数字要回到气象台原文核对
- **区分预报与实况**：气象局网站上的「城市 24 小时预报」「实况监测」是当天数据，不能当作假期逐日预报使用
- **标清时段与范围**：「10 月 1 日至 4 日」「江南、华南大部」这类限定词不能省，不得把区域预报写成全国
- **预报有时效**：文中要写明预报发布时间，并在结尾提示「以最新预报为准」
- **多股冷空气要分清归属**：哪一股影响哪个时段、哪个区域，不能合并叙述
- **气温写法跟官方口径**：用「21～25℃」，不用「21-25 度」；区间用波浪线，全文统一
- **灾种术语要准确**：山洪、地质灾害、中小河流洪水、森林火险分属不同部门的研判口径，不能混称，也不能替官方升级或降级风险等级
- **不与商业预报混用**：手机天气 App、聚合平台的预报不作为依据
- **景区天气分两级取数**：有景区专项预报（中国气象局名山景区稿件、景区气象站、市气象台景区专报）就用专项；没有才退到所在城市预报，并在表注里写明「所在城市预报值」
- **气温必须标明取值位置**：山顶 / 山上 / 高山景区 / 市区，四者温差可达 10℃ 以上。写「岱顶 5～17℃」「山上最低 3～5℃」，不能只留一个裸区间让读者误以为是山下气温
- **景区名后标注所在地**：用「泰山（山东泰安）」格式，便于读者对号入座，也便于核对数据出处
