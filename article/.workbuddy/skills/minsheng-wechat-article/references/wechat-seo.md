# 微信平台规范与搜一搜检索优化

分两部分：先讲平台硬性限制（不能违反），再讲检索优化（尽量命中）。

## 第一部分 · 平台硬性限制

以下为微信公众平台的官方口径，写作前先满足这些约束。

| 项目 | 限制 | 写作时的含义 |
| --- | --- | --- |
| 标题 | ≤ 64 字，不支持换行、不支持调整字号 | 列表页实际展示约 20 字，核心信息必须放在前 20 字内 |
| 摘要 | ≤ 120 字；**不填时自动抓取正文前 54 字** | 首段前 54 字必须能独立成句、且含核心关键词 |
| 正文 | ≤ 50000 字（含图片） | **不设篇幅要求**，以把事说清楚为准 |
| 封面大图 | 2.35:1，常用 900×383px | 左侧约 1/3 在部分场景会被头像遮挡，文案避开 |
| 封面小图 | 1:1，常用 500×500px | |
| 正文图片 | 宽度建议 1080px，PNG-24 压缩损失最小；单张像素乘积 ≤ 600 万 | |
| 修改限制 | 发表后仅可修改一次（标题 3 字、正文约 20 字、封面 1 张），以平台当前提示为准 | 标题和摘要必须在发布前定准 |
| 外部链接 | 仅认证服务号可插入 | 民生文章优先用公众号内部链接与话题标签 |
| 群发 | 订阅号每日 1 次，服务号每月 4 次，每次最多 8 篇 | 结合推送节奏安排发布计划 |

**纪律**：标题、摘要、封面三项在发布前必须逐字核对，发布后能改的空间极小。

## 第二部分 · 搜一搜检索优化

### 2.1 抓取与排序机制

**抓取重点：标题 + 导语（正文首段）**，其次是小标题与正文结尾。这意味着：

- 标题和第一段不是「写得好不好看」的问题，是「能不能被搜到」的问题
- 首段不要放「大家好，今天我们来聊聊」这类无信息量的开场，这段会被抓取，浪费了权重位置

**排序因子**（第三方研究口径，非官方精确值，仅作优化方向参考）：

| 因子 | 大致权重 | 对写作的启示 |
| --- | --- | --- |
| 内容相关性（关键词命中与语义匹配） | 最高 | 标题、摘要、首段、小标题都要自然覆盖读者搜索词 |
| 账号权威性（认证、垂直度、原创率、更新稳定性） | 较高 | 开启原创声明；把同主题文章归入合集，保持领域专注 |
| 用户行为（点击、完读、在看、收藏、转发） | 中 | 首段给结论能提升完读；结尾引导互动 |
| 社交关系链（好友读过 / 转发过优先展示） | 中 | 内容要有转发理由：实用、有明确结论、能帮到别人 |

原创声明与微信首发会被加权；搬运、伪原创降权。

### 2.2 关键词策略

**第一步：用读者的词，不用自己的词**

出发点必须是「读者会怎么搜」，而不是「我想怎么说」。

- 找词工具：微信搜一搜下拉联想、微信指数（对比热度）、搜索结果页的「相关搜索」
- 优先「高搜索量 + 低竞争」的长尾词：「灵活就业人员社保怎么交」优于「社保政策」

**第二步：搭关键词矩阵**

| 类型 | 数量 | 示例（以公积金为例） |
| --- | --- | --- |
| 核心词 | 1 个 | 公积金提取 |
| 长尾词 | 2-3 个 | 公积金提取条件、公积金提取需要什么材料 |
| 场景词 | 2-3 个 | 离职后公积金、租房提取公积金、公积金提取额度 |

**第三步：按权重位置布局**

优先级从高到低：

1. **标题** —— 含 1 个核心词，核心信息压在前 20 字内（列表页展示约 20 字，之后会被截断）
2. **摘要** —— 前 30 字嵌入核心词
3. **正文首段** —— 首 100 字内出现核心词
4. **小标题** —— 每节小标题融入长尾词或场景词
5. **正文结尾** —— 收束时自然再提一次

**第四步：控制密度与一致性**

- 核心词全文出现 3-6 次，整体关键词密度 < 5%
- **核心词保持统一表述，不要换同义词**（「公积金提取」和「提取住房公积金」会被当作不同词，权重被分散）
- 长尾短语不必逐字重复，语义覆盖即可

**禁忌**：堆砌关键词、蹭无关热门词、标题与内容不符 —— 会被判定为作弊降权。

### 2.3 摘要写法

**结构**：核心结论 + 关键条件或数字 + 对读者的价值

**长度**：≤120 字（平台硬限制）。不必凑长，也不宜过短——以核心结论和关键条件能说完整为准

**要求**：必须含核心关键词，前 30 字是重点

**禁止**：以「本文介绍了」「接下来我们来看」开头

**示例**

> 灵活就业人员社保缴费基数 2026 年起调整，最低档每月少缴 87 元。本文梳理调整范围、办理时间和线上缴费入口，帮你在截止日前办完。

### 2.4 标题写法

**候选数量**：5-8 个

**评估维度**：

1. 检索命中 —— 是否包含读者真实会输入的词
2. 信息量 —— 读完标题是否已经知道结论
3. 可读性 —— 是否通顺、不别扭、不像广告

**输出组合**：主标题 1 个 + 稳妥版 1 个（适合政务号、机构号，偏正式）+ 传播版 1 个（带明确结论，适合个人号）

**好标题的三种构成**

| 类型 | 结构 | 示例 |
| --- | --- | --- |
| 数字型 | 关键词 + 具体数字 | 养老金上调 3.8%，每月多领多少这样算 |
| 对象型 | 关键词 + 明确人群 | 灵活就业人员注意，社保缴费方式有变 |
| 动作型 | 关键词 + 怎么办 | 公积金租房提取，手机 3 步办完 |

**避免**

- 纯文学化标题（看不出在讲什么）
- 悬念式标题（「结果让人意外」）
- 空洞号召（「你必须知道」）
- 超过 25 字（展示会被截断）

### 2.5 可检索性附加项

- **话题标签（#）**：添加 3-6 个，参与分类与检索，标签本身应包含核心词
- **合集**：把同主题文章归入合集，提升账号垂直度
- **原创声明**：开启有助于权重
- **首段即结论**：同时满足阅读体验与检索需求
- **文内链**：关联往期同主题文章，提升完读率与垂直度

交付「发布包」时逐项核对：

- [ ] 标题 ≤ 64 字，前 20 字含核心词
- [ ] 摘要已手写（不依赖自动抓取），≤120 字，前 30 字含核心词
- [ ] 封面图 900×383px（大图），文案避开左侧 1/3
- [ ] 首段前 54 字可独立成句且含核心词
- [ ] 话题标签 3-6 个，含核心词
- [ ] 合集已关联
- [ ] 原创声明已勾选
- [ ] 来源清单已备
- [ ] 全文错别字与标点已核对
