# 平台合规与防限流

这份文档只回答一件事：**怎么写，才不会让文章发出去就被平台按住。**

公众号的「限流」分两种。**硬违规**有通知，删文或封号，通常踩的是明确条文；**软限流**没有通知，文章能发，但推荐池、搜一搜、看一看都起不来，实际曝光接近零。软限流更常见，也更难察觉——它不是玄学，是算法对「真人、有用、稳定」三项的判断结果。

防限流不靠规避技巧，靠不碰红线，加把这三项做出来。

## 一、两条官方红线

这两条是公众号平台运营规范里的明文条款，也是所有 AI 辅助写作的最大风险点。

### 3.27 非真人自动化创作

**禁止**：用 AI、脚本或接口替代真人完成「写 + 发」；用程序托管批量连发；售卖「自动写公众号」类工具或教程。

**后果**：流量限制、删文、封号。

### 7.4 低价值 AIGC

**禁止/降权**：AI 内容占主体却不标注「AI 辅助」；AI 编造事实、虚构数据、夸大表述；用简单提示词批量灌水。

**后果**：不进推荐池。注意是「不进推荐池」——文章还在，粉丝也收得到，但拿不到任何公域流量。

**平台的真实态度**：AI 可以当副驾驶，不能当替身主播。

### 对本号的含义

本号是民生号，做的是政策解读、数据发布、天气服务，这些恰好是**平台重点核查信源与真实性**的题材。具体三条：

1. **事实必须人工核过。** AI 找线索、列提纲可以，凡是进正文的数字、条款、时限，必须回到官方原文核对。这条与 `source-standards.md` 是同一件事，只是在这里多了一层平台风险。
2. **必须有人的判断。** 每篇文章至少要有 AI 给不出来的东西：这件事对哪类人影响最大、哪个数字最容易被误读、读者最可能在哪一步卡住。
3. **标注 AI 辅助。** 这是成本最低的一道保险，写在文末即可，模板见下一节。

## 二、AI 的边界：谁能做，谁不能做

| 环节 | AI 可以做 | 必须人工完成 |
| --- | --- | --- |
| 资料 | 检索线索、汇总多家来源、整理时间线 | 判断哪条可信，回到官方原文核验 |
| 结构 | 列提纲、给几种结构方案 | 定角度、定重点、定哪节先写 |
| 语言 | 校语病、断长句、去 AI 味 | 确定口吻与立场 |
| 标题 | 出候选、按规则打分 | 拍板，判断是否符合本文真实内容 |
| 案例 | 不能编 | 真实案例、真实场景、真实反馈 |
| 结论 | 不能替读者下断言 | 结尾的判断与取舍 |

**每篇自查三问**（写完对着文章答，答不上来就重写）：

1. 读者看完，多知道了什么？——认知、方法、信息、情绪，至少占一样。
2. 这句话换个人写得出来吗？——有本号的口径、本号的取舍，才算有「我」。
3. 事实能溯源吗？——政策、数据、言论、平台规则，任何一条都不能让 AI 代拟。

### AI 辅助声明（默认加在文末）

```
本文由作者选题与成稿，AI 仅用于资料整理和语句校对，核心观点与案例为人工整理。
```

写法上有两个细节值得注意：

- 写「**AI 辅助创作**」或「AI 辅助」，不写「AI 生成」「由某某模型生成」——后者会在平台的关键词判断里被直接归到 7.4 那一类。
- 声明要如实。如果这篇的事实核对、结构、判断都由人工完成，这么写就是准确的；如果整篇基本是 AI 出的，那问题不在声明，在流程。

## 三、内容层硬伤清单

以下每一条都对应平台明确的处置逻辑，写作与终检时逐项排除。

### 3.1 标题党

- 标题与正文脱节：标题给结论，正文其实没讲
- 「不看后悔」「震惊」「速看」「看完你就知道」类悬念与煽动
- 夸大式绝对承诺：「100% 有效」「一定通过」「躺赚」
- 蹭与内容无关的热门词

### 3.2 绝对化用语

《广告法》口径的词在民生文里同样敏感，尤其是带货段落。避免：

**最**（最有效、最先进、全网最低）、**第一**（全国第一、行业第一）、**国家级 / 世界级**、**根治 / 痊愈 / 保过 / 稳赚 / 零风险 / 绝对安全**、**100%**。

注意例外：**固定术语不算**。「最低工资标准」「最高缴费基数」「最低生活保障」都是法定名词，照写即可。判断标准是它是不是在给效果或品质下绝对判断。

### 3.3 无资质碰结论

以下领域的**结论性表述**必须有资质或权威来源，民生号只做「转述官方口径」这一件事：

| 领域 | 可以写 | 不能写 |
| --- | --- | --- |
| 医疗健康 | 医保报销范围、政策规定的待遇 | 诊断、用药建议、疗效判断 |
| 金融 | 存款利率、社保、公积金等政策数据 | 荐股、预测涨跌、推荐产品 |
| 保险 | 政策规定的基本医保与社保 | 具体产品优劣、理赔承诺 |
| 法律 | 条文原文、官方解释 | 代人下法律结论、承诺结果 |
| 时政 | 官方发布的事实与文件 | 解读、评论、预测政策走向 |

### 3.4 时事与公共政策：来源必须落地

平台对公共政策、社会事件的核查最严。本号的原则：

- 不用「网传」「据悉」「业内人士表示」「有消息称」代替出处
- 每条政策事实写清发文机关、文件全称与发布日期
- 官方没说的，不替它说；官方说得模糊的，保持模糊
- 政策解读不做政治性评论，只做「与读者有什么关系」

### 3.5 搬运洗稿

- 改语序、换同义词不算原创
- 大段整合公共信息（政策原文、公报数据、新闻通稿）不能标原创声明
- 引用他人报道要标来源；转载要授权

### 3.6 配图

- 不用来源不明的图、带水印的图、他人肖像未授权的图
- 不用 AI 仿冒真人照片、AI 生成的新闻现场图
- 官方图表可以用，标注出处

### 3.7 虚构演绎

剧情化写法、摆拍、模拟对话，必须显著标注「虚构演绎」或「场景示意」。民生号不建议用这类手法。

## 四、引流红线

正文与评论区都不要出现把读者往外带的动作：

- 微信号、QQ 号、手机号、二维码、外链、私域引流码
- 「关注后可见」「转发到 3 个群解锁」「私信领资料」「回复关键词领取」
- 「扫码进群」「加我好友」

广告与带货的处理：

- 放在文末，少量，标明「广告」或「合作」
- 整篇软广、硬广占比过高，账号会被判定为营销号
- 带货段落额外受《广告法》约束，绝对化用语零容忍

民政、人社类内容尤其注意：**正文里出现任何让读者「加微信咨询代办」的表述，是同时踩代办公信与引流两条线。**

## 五、运营层：让算法看到「正经号」

| 项目 | 该做 | 不该做 |
| --- | --- | --- |
| 垂直度 | 固定在一个领域（本号：民生） | 今天职场、明天养生、后天游戏 |
| 更新节奏 | 每周 2-3 篇稳定输出 | 断更半月，然后一天发 5 篇 |
| 数据 | 自然增长 | 买阅读、买粉、互阅互赞、机器点赞 |
| 修改 | 发布前定稿 | 发完反复改标题、封面、正文 |
| 账号资料 | 保持稳定 | 频繁改名、改简介、改头像 |
| 原创声明 | 与内容匹配时才用 | 活动公告、政策原文、天气、寻人、纯汇编标原创 |

**原创声明的界限要说清楚**：本号做的天气稿、政策条文整理、数据汇编，主体信息来自官方发布，**不宜标原创**；真能标的是自采的分析、自己的编排与判断形成独立表达的稿件。滥用原创声明会被判定作弊，权重损失比不标更大。

## 六、算法层：软限流的开关在这里

公众号的分发不是「发出来就有粉丝看到」，而是三段：

1. 先推给粉丝和小流量池
2. 看打开率、完读率、停留时长、点赞/在看/收藏/转发、搜一搜收录情况
3. 数据达标 → 进看一看、推荐、搜一搜；不达标 → 自然熄火

所以排版与检索本身就是防限流的一部分。四个可操作动作：

- **开头 60 字点题**。别写「大家好，今天我们来聊聊」——这段既是搜一搜的抓取位，也是完读率的起点。
- **每段 2-4 行，小标题清楚**。手机上划两下就要看到进展，否则直接退出。
- **文末问一个具体问题**。「你所在城市这项业务要几天办完」比「欢迎点赞在看」有效得多。
- **标题带精准长尾词**。三段式长尾词是搜一搜的真实检索形态，例如「社保缴费基数 怎么算」「婚假 几天」「高速免费 到几号」——题材词 + 读者的动作词。

## 七、本号的三个高风险场景

1. **政策解读**：不得替官方下达结论，不得把「试点」「研究」写成「落地」，不得用「必然」「一定会」。参见 `source-standards.md` 的表述纪律。
2. **数据发布**：必须给来源与口径。没写口径的数据会被当成编造，这是 7.4 里「虚构数据」的典型特征。
3. **天气与预报**：不标原创；不把预报写成实况；不用商业聚合源的数据。参见 `source-standards.md` 第八节。

## 八、已经被限流了怎么办

**错误动作**：狂发补量、删光重发、改名改定位、买量救场、在评论区求转发、信「解限流神器 / 强开推荐 / AI 去重包」。

**正确顺序**：

1. 删掉或隐藏低质稿、标题党、AI 直出稿、硬广稿
2. 连续发 3-5 篇垂直、有真事、有信息增量的文章
3. 自然启动：发到粉丝群、朋友圈，不机器刷
4. 7-15 天后看完读率与推荐占比，仍无起色就在后台「帮助与反馈」提交复核，附整改说明
5. 期间保持更新节奏不变，不要断更，也不要加倍发

## 九、交付前合规清单

- [ ] 每个数字、条款、时限都能溯源到官方一手
- [ ] 无绝对化用语（最、第一、国家级、根治、保过、稳赚、100%、零风险）
- [ ] 标题与正文一致，无悬念式、无夸大承诺
- [ ] 未对医疗、财经、保险、法律、时政下结论性判断
- [ ] 无「网传」「据悉」「业内人士表示」这类无出处表述
- [ ] 正文与文末无微信号、二维码、外链、私域码、「关注后可见」
- [ ] 配图来源清楚，无版权与肖像风险，无 AI 仿冒真人图
- [ ] 原创声明使用得当（天气、政策原文、纯汇编不标原创）
- [ ] 文末已加 AI 辅助创作声明
- [ ] 手机预览过一遍：封面清晰、摘要准确、段落短、无乱码

## 一句话版

别用 AI 代班，别标题党，别无资质讲医疗财经时政，别硬引流，别刷量，别一天发五篇水文；写「像活人写的、对读者有用、能搜到」的东西。
