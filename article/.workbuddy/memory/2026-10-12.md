## 环境优化：临时垃圾根治 + 效率约定

用户 2026-10-12 要求：临时文件单独放到一个临时目录，删除时直接删目录；同时要求不断优化回答效率、节省时间。做了一组对照实验，结果比"放临时目录"更省一步：

| 做法 | 根目录新增垃圾 |
| --- | --- |
| 纯 bash（ls / find / echo） | 0 |
| python（默认） | 约 20 个/次 |
| python `-s` | 约 20 个/次（无效） |
| python `-S` / `-E -s` / **`-I`** | **0** |
| python，仅 `TMPDIR` 指向 `.workbuddy/tmp` | root 仍新增 20，其余落 tmp |
| 工作目录 **与** `TMPDIR` 同时指向 `.workbuddy/tmp` | root 0，全部落 tmp |

- **根因**：沙箱拦截系统临时目录，Python 启动时加载用户 site 配置（sitecustomize）失败，把临时文件回退写到当前目录，每次约 20 个 4 字节文件。此前"逐批手删"的繁琐流程由此而来。
- **解法**：所有 Python 调用加 **`-I`**（隔离模式），垃圾直接归零——干净基线 0，连跑两次仍为 0。比"重定向到临时目录再删目录"少一步，且不必再为清理单独往返。
- **兜底**：万不得已时把工作目录与 `TMPDIR`/`TEMP`/`TMP` 都指到 `.workbuddy/tmp/`，删目录即可；只重定向 `TMPDIR` 不够。
